# EPUB／PDF 兼容说明

当前源码面向 Windows 11 x64。PDF 使用现有 pdfrx／PDFium；EPUB 使用 flutter_inappwebview 6.1.5、系统 WebView2 和本地 epub.js 0.3.93。JSZip 3.10.1 按 MIT 许可使用；依赖许可、下载来源、完整性与 SHA-256 记录在 `assets/epub/manifest.json`。

Windows 子插件固定 0.6.0，使用 `third_party/flutter_inappwebview_windows` 中的本地生命周期修正。只修正环境通道 ID、可等待且去重的原生关闭及导出，原生桥接迟到回执的生命周期检查，以及自然退出时消息队列和合成资源的释放顺序；上游文件与改动文件分别由哈希清单记录，许可随包保存。详情见该目录的 `OPENNOTE-PATCH.md`。真实关闭须等待原生回执，控件卸载后的 JS 回调不作为关闭确认。

| 能力 | PDF | EPUB |
| --- | --- | --- |
| 混合导入、首页封面、标签与回收站 | 原件托管 | EPUB 2／3，OPF、spine、NCX／nav、封面与阅读方向 |
| 阅读 | 页码、缩放、原页面布局 | 单栏连续／分页，字号、字体、行距、页边距；固定与混合版式、竖排、内部链接和脚注 |
| 正文与图形 | 原生内容或扫描图像 | 正文、表格、图片、SVG、MathML、内嵌字体 |
| 卡片与脑图 | 文字、页面区域截图 | 文字、原图、可见区域截图，摘录按钮可拖入脑图 |
| 批注、思考、颜色、撤销与独立复制 | 共用仓储 | 共用仓储，来源使用 EPUB CFI |
| 搜索 | 原生／OCR 文字层 | 逐章正文索引及按需图片 OCR，结果带 CFI 来源 |
| 保存与完整恢复 | 页码与页面坐标 | 章节、CFI、阅读设置、截图和 OCR 结果 |

资料入口为“添加文档”，可同时选择 PDF 与 EPUB。EPUB 选中文字后点击摘录，或把摘录按钮拖到脑图；右键图片后可摘录原图。工具栏“区域摘录”保存当时可见的截图，“更多阅读工具”提供批注、阅读设置、索引暂停／继续与按需图片识别。图片识别结果可选择文字再摘录，不覆盖原生正文或旧卡片。固定版式提供缩放；窄栏在菜单中保留收纳的操作。

固定版式缩放扩大实际阅读视图并允许滚动，缩放比例随阅读设置保存。混合版式按当前章节切换排版能力。样本中的 SVG 为 XHTML 内嵌 SVG；独立 SVG spine、特殊厂商扩展和复杂数学字体的所有组合尚未穷举，兼容结论以具体样本与真实程序报告为依据。

EPUB 来源绑定原件版本、章节路径、CFI 点／范围和原文校验信息；图片区域使用相对裁剪。改变字号或窗口后不会把临时重排页码作为来源。回源内容或上下文不一致时明确失败，不跳转到相似段落。

只支持无 DRM 的书籍及标准 IDPF／Adobe 字体混淆。书籍脚本、音视频、外网资源、DRM 授权、云同步和批注写回不在范围内。损坏 ZIP、资源路径越界、符号链接、缺失资源或非标准加密会拒绝导入。单文件上限 512 MiB、解压资源总计 1 GiB、单资源 128 MiB、资源数量 20,000；这些是明确的导入边界。

仅使用系统 WebView2，包中不附带运行时或安装器。缺失时 EPUB 显示安装提示，PDF 仍能阅读。运行时安装属于系统准备；本软件的书籍正文和学习资料处理保持离线。

自产样本位于 `tools/fixtures/epub`，由 `tools/epub/create_fixtures.py` 生成；包含 EPUB 2／3、横排、中日韩竖排、固定与混合布局、图片、脚注、表格、SVG、MathML。自行指定的测试书籍须有使用权限，并只在独立临时资料库中验证，不纳入源码或分发包。

日常验证使用 `tools/dev/flutter_dev.py check --scope epub`。真实原生渲染使用 `tools/epub/run_probe.py`，真实混合工作台使用 `tools/epub/run_workbench.py`；后者强制独立资料库。可通过 `OPENNOTE_EPUB_REAL_BOOK` 指定本机书籍。迁移、原生依赖及跨层变更完成后串行执行一次 `check --scope full`。结果、未覆盖项和候选包身份保存到本地忽略目录，替身测试不能证明原生交互已验收。
