# OpenNote 0.1.0 功能与维护基线

平台：Windows 11 x64。许可证：Apache 2.0。数据库 schemaVersion 11，备份 formatVersion 1。当前源码持续维护；分发和验证状态以实际产物为准。

| 功能 | 当前范围 |
| --- | --- |
| 学习项目 | 一级分类、全局名称搜索、封面、阅读位置、PDF／EPUB 混合资料 |
| 阅读与 OCR | 原生/扫描 PDF、无 DRM EPUB 2／3，中英印刷文字离线识别与搜索 |
| 摘录与批注 | 文字、图片、区域截图、应用内高亮、来源定位及回源 |
| 卡片与脑图 | 独立卡片、分条个人思考、常驻编辑器、结构编辑、关联、外框、概要和格式 |
| 编辑与资料管理 | 自动保存、多选、剪贴板、重命名、会话撤销重做和回收站 |
| 备份与恢复 | 包含原文和附件，升级前一致性快照，暂存校验后切换资料库 |
| Windows 分发 | 完整便携包、安装包与源码包；保留第三方许可和来源声明 |

操作见 [使用说明](user-guide.md)，功能与数据安全合同见 [架构](architecture.md)和[数据模型](data-model.md)，视觉以 [UI 设计](ui-design.md)为准。

不包含云同步、云端 AI、平板压感手写、复习系统、标准 PDF 批注写回或完整 Xmind 交换。脑图基础能力及剩余项见 [编辑对照](xmind-basic-editing.md)。

保持独立卡片、原文版本、PDF 页面坐标、EPUB CFI、离线 OCR 和完整备份合同。架构或持久化变化须同步迁移与文档；历史成功不能代替当前验证。构建见 [Windows 构建](build-windows.md)，检查见 [验证方法](validation.md)。
