# UI 验证入口

当前视觉以 [UI 设计](ui-design.md)为准。组件与页面使用真实工作台及自产演示资料，回归基线见 `test/goldens/baseline-environment.json`。

根据修改范围选择组件测试、单一尺寸 Golden、响应式/DPI 配置或实际 Windows 交互。Profile 只用于性能变更；不得把截图或局部通过描述为完整运行验收。

方法见 [Flutter 开发](flutter-development.md)、[分级验证](testing.md)及[验证范围](validation.md)。内部历史报告与截图留在本地忽略目录，不随源码分发。
