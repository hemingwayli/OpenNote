# Xmind 基础编辑对照与实施进度

目标：让习惯 Xmind 的用户能在 OpenNote 完成基础主题编辑与知识组织。视觉统一以 [UI 设计准则](ui-design.md) 为准；本文件仅记录编辑功能对照、PDF 来源、独立卡片、事务保存和撤销合同。

当前源码数据库为 v11；基础能力与尚待完善项如下，真实 Windows 综合操作需按对应版本验证。

对照依据为 [Xmind 主题操作](https://xmind.cn/user-guide/topic-editing-new)、[结构](https://xmind.com/user-guide/structure-new)、[关联线](https://xmind.com/user-guide/relationship-new)、[外框](https://xmind.com/user-guide/boundary-new)、[概要](https://xmind.com/user-guide/summary-new) 与 [分支](https://xmind.com/user-guide/branch-new)，于 2026-10-05 核对。目标是常规桌面编辑，不据此宣称复制整个 Xmind 产品。

## 交互合同

节点单击仍按联动模式回到 PDF；画布和大纲的标题双击进入局部标题编辑，画布正文双击、F2 或右键编辑打开共用卡片面板。面板在同项目内常驻，单击其他卡片先保存旧草稿再切换，不抢正文焦点；空白点击只清除选集，PDF 和画布/大纲操作保持面板。切图或目标删除后显示“请选择卡片”，叉号先保存再关闭，失败保留草稿，关闭后普通单击不重开。返回首页、更换项目或资料库会话后重置。

明确编辑保留正文焦点语义；标题草稿携带脑图、节点、卡片和编辑代次，保存失败留在原位，返回首页、切换视图和其他业务命令先提交。视图切换保持共用编辑器子树与草稿，不因纯显示变化强制保存正文。画布右键的样式、复制与移动、折叠与展开使用紧凑子菜单；画布右下角合并为「新建／更多／适合全部」，不显示缩放加减按钮；结构、框选、关联、外框和概要通过「更多」进入，结构使用侧向子菜单，大纲保留页头入口。模式提示位于工具组上方，Esc 退出；滚轮与捏合缩放保留。

框选工具开启后从空白处拖动，或临时按 Shift 拖动；普通空白拖动仍平移。选框按当前相机变换命中可见节点，不命中折叠后代；Ctrl／Shift 追加选择，抬起才向工作台交接一次选集。Esc、指针取消或切图不提交预览。大纲 Shift+方向键使用连续范围，反向移动可收缩；这些操作不自动跳转 PDF。

剪贴板对外提供 Tab 缩进的主题标题；应用会话内同时保留完整内容快照。复制后的原卡变化不会改变粘贴内容。剪切先保留原分支，粘贴成功后才移动；同项目移动保留身份，跨项目使用复制并映射原文来源。资料库切换或系统剪贴板内容改变后不再使用旧内部记录。纯文本最多一次粘贴 2000 个主题，非法层级整批拒绝。


## 数据与验证

结构、复制、样式、来源和撤销通过仓储事务持久化。升级前保存含 WAL 的一致性快照，恢复在暂存资料库校验成功后激活。数据库与备份合同见 [数据模型](data-model.md)。按 [分级验证](testing.md)检查脑图、工作台与相关数据范围，实际交互按需要补 Windows 验证。
