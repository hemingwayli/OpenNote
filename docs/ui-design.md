# OpenNote UI 设计准则

更新日期：2026-10-09。本文是项目唯一有效的视觉规范。实现须同时符合 [UI 行为合同](ui-behavior-contracts.md)。

## 方向与边界

采用当前的 Xmind 风格：连续的白色工作空间、居中的悬浮工具条、独立的小型按钮组和干净留白。布局比例清晰，少量蓝色用于活动工具、焦点和关键状态，阅读内容保持最高视觉分量。

首要视觉顺序是 **PDF 阅读 → 右侧脑图 → 辅助工具与资料**。主工作区默认按 58%／42% 分配阅读区与脑图区，保留手动分栏。全局命令留在窗口顶部，阅读命令留在文档内，脑图命令精简为右下角一组「新建／更多／适合全部」，其余画布操作由「更多」收纳。资料管理与当前对象编辑不得获得与阅读正文相同的视觉分量。

界面呈现与布局调整须保留所有既有功能、打开与关闭方式、快捷键、保存时机、撤销重做和数据格式。样式弹窗仍通过“应用／取消”结束，不引入即时应用或自动弹出工具。现有交互合同见 [UI 行为合同](ui-behavior-contracts.md)。

## 色彩、字体与控件

| 用途 | 值 | 使用规则 |
| --- | --- | --- |
| 辅助背景 | `#F4F5F6` | 侧栏、阅读纸张外部；主工作空间保持白色 |
| 内容表面 | `#FFFFFF` | 页面、画布、卡片和弹窗 |
| 边框 | `#E7E8EA` | 细边界，不连续堆叠多层边框 |
| 主文字 | `#292C30` | 内容、标题和工具图标 |
| 次文字 | `#73777D` | 元信息和辅助说明 |
| 悬停背景 | `#F0F1F2` | 轻量鼠标反馈 |
| 选中背景 | `#E9EAEC` | 中性选中面，不铺大面积强调色 |
| 强调色 | `#3574CB` | 用于少量活动图标、焦点和关键状态 |
| 错误色 | `#BA3434` | 仅用于错误和危险语义，不与普通强调状态混淆 |

- 沿用 Segoe UI 与随应用分发的思源黑体简体中文，保留原有字重与字体许可。正文 16／1.6，导航 14，辅助文字 12；页面标题 24，内容区标题 18。已有节点文字和内容格式按用户保存的样式呈现。
- 工具按钮通常仅显示图标；脑图「新建」保留简短文字以区分缩放与创建。悬停 450 毫秒后显示名称与已有快捷键。命中区至少 36×36，保留键盘焦点、无障碍名称、选中和禁用状态；几何编辑与折叠控件沿用现有专用命中范围。
- 所有应用自有操作图标统一使用 `OpenNoteIcon`：24 单位坐标、1.7 单位圆头圆角笔画，常用工具显示 20，辅助标记 16–18。相同操作使用相同轮廓，不混用实心与空心版本，不新增字体或运行时依赖。
- 工具组内边距 2、圆角 7，阴影仅向下 1、模糊 5、低透明度。工具组应轻于阅读内容，禁止用大范围阴影制造蓬松效果。
- 导航标题、字段标签、菜单项目、表单确认／取消／危险操作及必要的空状态引导保留简短文字。
- 圆角以 6–10 为主，弹窗 12；浮层使用轻微向下阴影，不使用双向凸起效果。表单输入采用白底细边框。
- 用户保存的卡片、节点、分支、外框、概要和批注配色属于内容，不能随应用主题批量改写。

## 页面组织

- **一体式窗口顶部**：高度 56，左侧为主页与标题，常用工具在整窗中线附近悬浮，右侧是独立视图工具组及窗口按钮。顶部保持连续白色背景，标题与指定空白区可拖动，按钮区域独立命中。普通还原窗口四角采用系统圆角，最大化和全屏使用直角；最大化按钮根据实际状态显示最大化／还原图标。支持原生边框缩放、系统贴靠、DPI 变化与关闭前保存。
- **首页**：采用白色封面展陈布局，灰色分类侧栏保持原有导航。书格宽 200，列间距 64、行间距 48，窗口增宽只增加列数，不拉伸书格；窄窗口按可用宽度换行。封面区域高 232，按原比例完整显示并左下对齐，轻阴影贴合封面；无封面时使用中性竖向书本占位。静止时无外框或灰白分区，悬停使用极淡背景，键盘焦点显示细蓝色轮廓。项目名左对齐，16／1.4、中等字重，最多两行，保留完整名称提示和 36×36 的独立管理菜单。最近打开使用 11／1.4 的浅灰字（`#8A8E94`），紧跟标题下方，间隔 4，不为单行标题预留第二行空白；数量信息与完整分类、日期收在该行的详情提示中。标题与搜索、排序、新建共用操作行，宽屏附带当前项目数；分类说明与书格之间用一条细分隔线。搜索展开、焦点、分页与滚动恢复保留原有逻辑。
- **阅读工作台**：白色内容区域与脑图画布连续铺开，资料栏保持中性浅灰。资料栏当前项使用白色圆角选中面，当前文档／脑图图标小范围使用蓝色；行菜单统一为线性省略号。操作由轻浮动工具组组织，区域通过布局、留白和细分隔线区分。
- **PDF／EPUB**：项目仅有一份文档时收起名称／标签行，让阅读工具栏直接位于窗口顶部下方；项目有多份文档时保留 40 高的已打开文档标签行。阅读工具栏 44，工具随面板宽度收纳，页码导航与缩放各自成组。PDF 纸张外部浅灰，EPUB 正文保留用户阅读设置；章节进度、批注、摘录和阅读设置遵守当前交互合同。
- **脑图／大纲**：纯白画布，仅有一张脑图时隐藏名称，多张时显示当前名称；保留视图切换入口。画布右下角仅保留「新建／更多」与细分隔线后的「适合全部」。新建直接创建主题；结构与整理、框选、关联、外框和概要收纳于「更多」，结构使用侧向子菜单。画布不显示缩放加减按钮，保留滚轮与触控板捏合。框选／关联模式用工具组上方的小型浅蓝提示和 Esc 退出说明表达；大纲保留页头新建与结构入口。大纲使用 `#F4F5F6` 选中面，主选行以 `#E7E8EA` 细轮廓及现有标题字重区分，避免整行深色描边；保留用户内容颜色、字号和格式。
- **卡片编辑**：白色笔记表面，顶部以 13 号灰字标明“卡片笔记”；内容区左右内边距 24、顶部 12，卡片标题 20／1.5，正文 16／1.6。正文、思考和来源的辅助标签约 12，标题与正文之间使用轻分隔线及 12／16 间距。思考条目浅灰底，静止时无描边，聚焦后显示细蓝色轮廓。宽屏停靠编辑区无阴影，窄屏浮层仅保留高度 1 的轻阴影。必要时仅平移脑图以保留当前卡片的可见性，不改变缩放、选择或输入焦点。色板与回源入口继续由现有内容状态决定。
- **弹窗和菜单**：新建、改名、搜索、主题格式、关系、外框、概要、结构、回收站、备份恢复、关于和许可页面统一继承主题。保持原有字段、确认动作和错误说明，不删除不可逆操作提示。

## 右键菜单

脑图、大纲、PDF 选区、关联线和外框的右键菜单，以及打开同一菜单的省略号入口共用以下规范。各菜单保留现有命令、顺序、分组、快捷键和可用条件；脑图右下角“更多”也共用以下展示、动画与导航规则，从工具组上方展开；首页、其他工具栏“更多”和其他弹出菜单沿用各自入口。

- 菜单白底、8 圆角、淡边框和轻阴影，上下内边距 6、行内左右内边距 12。正常宽度按内容测量为 220–320，文字放大时适当增宽；行高至少 36，换行和文字缩放时增高。超高菜单在内部滚动。
- 线性图标 18、名称 14、快捷键 12；图标、名称、右对齐的次文字快捷键和子菜单箭头分列。没有快捷键的项目让名称使用空出的空间。悬停及展开中的父项使用浅灰反馈，禁用项降低对比度，危险操作使用错误色。
- 主菜单和子菜单均以最终尺寸、最终位置整块同步淡入淡出，时长各 120 毫秒。所有项目同时出现，不使用宽高展开、逐项淡入、缩放或滑动；减少动画时直接显隐。
- 子菜单在父项侧面展开，父菜单保持原位，默认向右、空间不足向左，间隔 4。鼠标悬停 250 毫秒展开，点击或键盘立即展开；移出父项保留 200 毫秒，斜向移入子菜单有保护区域，进入后保持打开。
- 首次定位预留子菜单空间，距离窗口边缘至少 8。窄视口的两列分别限于可用宽度的一半，长名称换行。子菜单入口使用箭头，打开弹窗的操作保留省略号。
- 上下键浏览，右键进入子菜单，左键返回父项，Enter 执行，Esc 逐层关闭。外部点击关闭整组并消费该次点击，菜单关闭恢复焦点。

## PDF 阅读布局与辅助反馈

- **页码导航**：通常显示为 `‹  [1] / 242  ›`，当前页和总页数统一为 14 号、等宽数字和相同文字基线。输入框高度 32、圆角 6，宽度按实际文字缩放预留四位数字、内边距和光标，翻页时保持稳定。平时一层淡边框，获得焦点后突出同一层边框；左右箭头、输入和总页数间距保持一致。
- **目录与居中**：停靠目录占用阅读区左侧空间，PDF 在剩余阅读视口内居中。适合宽度／整页模式在目录开关、拖宽和窗口变化后持续适配，并保留纵向阅读位置；手动缩放保留当前缩放与阅读锚点。窄栏使用目录抽屉。
- **目录分隔线**：保留 6 像素拖动区和一条淡分隔线。鼠标经过显示左右调整光标，分隔线略微加深；拖动时加粗并强调。分隔处没有常驻拖动图案。
- **目录记忆**：每份 PDF 分别保存目录开关和宽度，切换文档、返回项目和重启后恢复。窗口临时变窄只限制实际显示宽度，不覆盖保存的宽度偏好。
- **文字识别**：处理中的进度、失败后的重试和取消后的继续入口保持可见。全部页面就绪、没有活动任务与错误时，提示“文字识别完成”约 1.8 秒，隐藏状态按钮并收回占位；已完成文档再次进入不重复提示。状态详情位于窗口顶部“更多 → 文字识别状态”。
- **滚动条**：滚动时显示，闲置 1.5 秒后用 200 毫秒淡出；鼠标进入右边缘时唤出，悬停或拖动期间保持可见，离开后重新计时。启用减少动画时保留相同显隐规则，省去淡入淡出动画。

## 响应式与验收

保留现有显示条件：资料栏在 1280 逻辑像素以上显示，宽 208；编辑区宽 360，仅在编辑时出现。1600 以上优先从右侧脑图区让出编辑空间，脑图至少保留 280 宽，可继续点击切换卡片；空间充足时 PDF 宽度不变。1600 以下使用带边距的右侧编辑浮层。首页分类在 760 以下进入抽屉。窗口顶部按扣除系统操作区域后的实际可用宽度收纳工具，禁止遮挡或挤掉命令。编辑器、阅读器和画布不因尺寸变化而替换会话。

视觉检查使用真实组件与隔离资料库，默认比较 1920×1080／DPR 1 的 11 张页面基线。涉及响应式、DPI 或字体时补充对应尺寸；整体视觉变化和发布验收才使用全部 33 张配置，并检查小窗口与文字放大。窗口生命周期与原生集成使用相关行为测试和真实 Windows 程序验证。测试与截图方法见 [分级验证](testing.md)。

字体原文件、许可证与固定来源见 `assets/fonts/source-han-sans/`；继续保留应用内开源许可登记。历史报告不能替代当前实际检查。
