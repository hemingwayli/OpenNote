# OpenNote 使用说明

更新日期：2026-10-08，适用于 Windows v0.1.0 当前维护源码。UI 设计以[UI 设计要求](ui-design.md)为准；功能边界见[维护基线](implementation-v0.1.0.md)，数据处理见[隐私说明](privacy.md)。

## 建立学习项目并导入文档

1. 启动后始终进入项目首页。点击「新建项目」，输入名称；项目归入当前文件夹，并建立一张默认脑图后进入阅读。
2. 单击项目卡片（或聚焦后按 Enter）继续阅读。首页支持一级文件夹、全局项目名称搜索，以及最近打开／名称／创建时间排序。卡片显示最近阅读文档的 PDF 第一页或 EPUB 封面和资料数量；没有封面时显示占位图。
3. 点击「添加文档」，可一次选择多份 PDF 与 EPUB。应用复制原文件到本机资料库，阅读与摘录不修改原文件。
4. 从资料列表打开文档后，可调整文档标签顺序；关闭标签只关闭当前视图，原文、摘录和阅读位置均保留，可从资料列表重新打开。「新建脑图」可为项目增加脑图。

项目、文档和脑图支持「重命名」。重命名保留原有资料和来源身份，并可在本次会话撤销。筛选功能用于按名称查找文档与脑图，卡片筛选同时查找标题、正文和各条个人思考。

阅读页左上角的「返回项目主页」会保存草稿、标签顺序、当前脑图和阅读位置。保存失败会留在工作台，可处理错误后重试。返回首页不会中止已接受的 OCR 任务。

项目的重命名、移动分类和移入回收站统一放在首页卡片菜单。文件夹只支持一级，删除文件夹会把项目移到「未分类」。搜索覆盖全部文件夹，清空搜索后恢复之前分类与滚动位置。

## 阅读与摘录

阅读区提供页码、缩放、适应宽度、页面显示旋转，以及目录和缩略图入口。页码按 `‹  [1] / 242  ›` 成组显示，输入当前页后按 Enter 跳转；输入框可容纳四位页码，获得焦点时边框突出。应用保存阅读位置。显示旋转不写回原 PDF。

EPUB 阅读区显示章节和进度，默认单栏连续阅读。「更多阅读工具 → 阅读设置」可调整字号、字体、行距、页边距与分页模式；固定版式使用缩放。选中文字后可点击摘录，或将摘录按钮拖入脑图；右键图片可以摘录原图，区域工具保存截图。图片或截图选中后可按需识别文字，并从识别结果选文摘录。正文索引逐章自动建立，菜单支持暂停与继续。来源使用章节及 CFI，重排、重启和完整恢复后继续回源；校验失败会显示错误。详细边界见 [兼容说明](epub-pdf-compatibility.md)。

- **复制和选词**：在「选文」模式拖选后按 `Ctrl+C`，或右键选择「复制选中文字」；也可从上方「更多阅读工具」菜单复制。跨页选区按阅读顺序复制，页面之间保留换行；尚未完成文字处理的选区不会复制残缺内容。双击文字按 Unicode 词边界选词，中文不按空格切分。
- **调整选区**：拖动蓝色起点／终点手柄；PDF 获得焦点后，按 `Shift+左右方向键` 调整选区，`Shift+上下方向键` 按文本行扩展，`Shift+Home/End` 延伸到行首／行尾。选择结果仍可直接摘录或批注。
- **选文时阅读**：选文模式下仍可使用滚轮或触控板双指滑动，滑动不会产生选区。按住鼠标拖动才选文，双击文字选词；单击阅读区空白处取消上次选区，随后可重新选择。
- **缩放和定位**：上方单行工具栏提供放大、缩小与适配；「更多阅读工具」可选择适合整页，适合页面宽度保留直接入口。工具栏不显示百分比，也不提供数值缩放输入。窄栏将部分工具收进菜单，页码和目录继续保留，OCR 入口根据处理状态显示。右侧滚动滑块可拖动定位整本 PDF，悬停显示当前页／总页数；滚动时出现，停止约 1.5 秒后淡出，鼠标靠近右边缘可唤出，悬停或拖动时保持可见。
- **鼠标滚轮**：沿用 Windows 的滚动行数，以平滑过渡滚动；PDF 放大、缩小后，每格滚轮的屏幕移动距离保持一致。连续滚动可累加，反向滚动立即换向；点击、拖动或跳页会打断余下过渡。`Ctrl+滚轮` 仍以鼠标位置缩放，`Shift+滚轮` 横向移动。
- **目录**：章节左侧箭头展开／折叠子章节，点击标题跳转。拖动目录右边界调整宽度，鼠标经过边界时显示左右调整光标且分隔线加深；长标题悬停可查看全文。每份 PDF 分别记住目录开关和宽度，重新进入项目或重启后恢复。打开目录后 PDF 在剩余阅读区域内居中，宽度／整页适配继续生效；手动缩放保留当前缩放和阅读位置。窄分栏会临时限制目录宽度，较窄时改用抽屉，点击遮罩、关闭按钮或按 Esc 可收起；临时布局限制不改写保存的宽度。

PDF 自带的文内链接可在移动、选文和矩形工具下点击跳转；链接与 OpenNote 批注重合时先处理批注，拖选文字或矩形不会激活链接。无法跳转的目标会显示反馈，后续翻页仍可继续。首版支持 PDF 文内跳转，不直接打开外部网页链接。

- **文字摘录**：使用选文工具，在 PDF 上拖动选择文字，点击「摘录」。原生 PDF 直接提取文字；纯扫描页先执行本机离线 OCR，文字就绪后可以选文、搜索和摘录。
- **区域摘录**：切换矩形工具，框选单页区域，点击「摘录」保存区域图片及来源。适合图片、公式或文字识别不准确的部分。
- **加入主题**：先选中脑图中的主题，再摘录，生成的卡片放在该主题下；未选主题时放在顶层。
- **应用内批注**：对选区创建高亮或文字备注。批注随资料库保存；首版不把批注写回标准 PDF 文件。

导入或打开 PDF 会自动补齐缺失文字索引，无需手动启动。处理期间，阅读工具栏右侧显示当前文档的状态与页数进度，点击可「取消处理」；失败时可查看原因并「重试失败页面」，取消后可「继续处理」。全部页面就绪且没有活动任务与错误时，短暂提示「文字识别完成」，状态按钮隐藏并收回位置；完成后仍可从窗口顶部「更多 → 文字识别状态」查看详情，重新进入已完成文档不重复提示。重试只恢复失败页，继续只恢复取消页，均保留已完成页；取消仅影响当前 PDF。PDF 收起后，页头保留当前文档的处理中、失败或取消状态入口。队列优先当前阅读页，再按距离处理附近页面（等距先下一页）；翻页立即更新待处理队列的顺序，已经开始识别的单页先完成。已完成页直接复用，翻页不会重新启动已取消或失败的页面。正常退出会等待已接受的编辑和当前处理页保存，剩余任务在下次启动续跑。扫描 OCR 处理中文与英文印刷内容；识别结果与字符位置可能有误差，多栏、复杂排版、模糊和倾斜书页需要实际检查。手写识别不属于首版。

## 整理脑图与编辑卡片

右键菜单采用白色小面板和整块淡入淡出。“复制与移动”“样式”“折叠与展开”右侧箭头表示子菜单，悬停片刻或点击后在侧面打开，主菜单继续保留；名称末尾的省略号表示打开设置弹窗。上下方向键选择命令，右方向键进入子菜单，左方向键返回父项，Enter 执行，Esc 逐层关闭。点击菜单外只关闭菜单，不触发底层操作。大纲的省略号按钮打开与右键相同的菜单；菜单内容较长时可在菜单内滚动。

新建项目的初始脑图和单独新建脑图默认采用向右自动排版：父主题在左，子主题在右，同级上下排列。已有脑图保留各自保存的结构，仍可通过结构菜单选择自由布局。

拖入另一主题成为子主题后，卡片及后代按目标结构排布，不保留重叠的鼠标落点。目标父级为自由布局时，自动把该父级的局部结构改为向右展开；在自由图中固定父主题、整理其子树，其他独立分支保持原位。内层已明确指定的结构继续保留。这次结构调整、挂接和排版共用一次保存及撤销。

画布右下角「新建」直接创建主题，选中主题时沿用子主题创建规则；「适合全部」可一次看全卡片。画布缩放使用滚轮或触控板捏合，工具组不再显示加减按钮。框选、关联模式在工具组上方显示提示，可按 Esc 退出。选中主题后可新建子主题；拖动主题到另一主题上重新挂接。自由位置可拖到空白处调整，自动排布位置松手后归位。折叠可收起子树，鼠标滚轮缩放，拖动空白区域平移。画布右下角「更多 → 脑图结构与整理」子菜单（大纲仍使用页头入口）提供自由布局、向左／向右逻辑图、双侧脑图及向上／向下组织结构；「更多结构…」用示意图选择左右树形图、左右大括号图、横向／纵向时间线和左右头向鱼骨图，每张图保存自己的选择。「自动整理」沿当前结构排布；自由布局第一次整理采用向右逻辑图。

结构模式中新建、同级排序、重挂、删除和展开会按当前结构重新排布。自动布局的根主题拖动用于平移整张画布，不保存节点位置；普通自动节点可预览拖动，空白松手后归位。自由布局的根主题仍移动自身及分支。切回自由布局保留当前位置。双侧脑图的大纲主题菜单可将整枝移到左侧／右侧；新增同级主题沿用目标分支的方向。结构菜单提供收起全部、展开到第 1／2／3 层和展开全部，中心主题为第 0 层。方向键按可见结构浏览：左右图沿左右方向进入子主题，上下图沿上下方向进入子主题，另一方向浏览同级；Home 回到首个中心主题，End 到最后可见主题。

同一张图可以混合分支结构。大纲主题菜单的「分支结构…」，或画布「更多 → 脑图结构与整理 → 所选主题分支结构…」（大纲仍使用页头结构入口），可对精确多选主题指定上述任一结构。「跟随上层结构」移除局部覆盖；默认保留内层已设置的结构，勾选「同时重置内层分支结构」才统一重置。全图切换继续保留局部覆盖。局部双侧的左右菜单移动最近双侧主题下的整枝；自由分支保留手工相对位置。

拖到主题中间会提示「加入子主题」；结构布局中拖到主题前后区域会显示「插入前面／后面」和蓝色插入线，水平分支使用上下区域，垂直分支使用左右区域。自由父级只有成为子主题的提示，其子主题的空白落点仍保存自由位置。有效挂接或插入松手后，层级、顺序和排布一次保存／撤销；Esc、旧目标变更或保存失败取消预览。混合方向下箭头沿实际画布位置浏览，折叠主题沿子分支方向先展开。树形图按左右方向进入子主题／返回父主题；时间线和鱼骨图沿主轴方向依次浏览普通同级主题，不把概要插入事件顺序。鱼骨图头向右时，沿向左方向浏览后续原因分支；主轴上的前后插入提示也随头向调整。

画布卡片右键菜单提供新建子主题和同级主题；`Shift+Enter` 插入前面的同级主题，`Ctrl+Enter` 插入上层主题。子主题放在操作目标下，同级主题沿用操作目标的父级；上层主题包住被选分支。双击脑图空白处在该位置创建顶层主题，即使原来选中了父主题也不改变此规则。画布快捷创建后直接编辑标题；这些主题没有原文来源，原卡片的正文、个人思考及来源不会复制过去。

在画布或大纲中双击标题、按空格键，可直接编辑标题；Enter 保存，Esc 取消，Tab 保存后新建子主题。画布标题支持 Shift+Enter 换行，大纲标题使用单行输入。中文输入法尚在组词时，Enter 交给输入法；保存失败保留草稿。画布双击卡片正文或两个视图中按 F2 仍进入正文编辑器。标题草稿会在返回首页、切换视图或执行其他命令前保存。

脑图焦点下，Ctrl+C 复制完整所选分支；Ctrl+X 准备剪切，Ctrl+V 粘贴到当前主题下（没有选择时粘贴为顶层）。副本拥有独立正文、个人思考、颜色和来源，内部关联跟随复制。剪切粘贴成功才移动，失败保留原数据；跨项目移动请改用复制。外部纯文本按 Tab 或四个空格的缩进转换成主题层级。

脑图可切换「画布／大纲」。大纲按层级列出同一批卡片，提供「单行显示」与「显示正文」；正文模式可阅读长正文、个人思考和摘录图片。两种视图共用选中及分支折叠，切换保留画布位置与共用正文编辑器的草稿；视图本身不产生撤销记录，改过的标题作为一次编辑保存，失败时不切换。结构模式同层按保存的主题顺序浏览，不因左向／上向坐标而反转；自由布局仍按位置浏览。

在画布或大纲中按住 `Ctrl` 完整点击卡片，可加入或取消多选；最后加入的卡片是主选。Ctrl 点击只选择，不自动跳转 PDF。普通完整点击恢复单选，两种视图保留同一组选中卡片，折叠不会清除隐藏后代的选择。

画布右下角「更多 → 框选卡片」可开启框选模式，再从空白处拖出选框；也可临时按住 Shift 拖动空白区域。Ctrl 或 Shift 框选追加原选集，普通框选替换原选集，只命中当前展开可见的节点。抬起鼠标才确认选择；Esc 或取消鼠标手势恢复原选区。未开启框选时，空白拖动仍平移画布。大纲中上下方向键逐行浏览，左右折叠／展开或跳到父子主题，Shift+上下方向键选中连续范围，再反向移动可缩小范围。这些选择不自动跳转 PDF。

多选后，可编辑主选卡片、回到其原文，以及批量改色、折叠、展开或回收分支。批量改色作用于精确所选卡片及其明确关联的 PDF 标注，其他卡片和无关联标注保持原值；回收分支包含所选节点的全部后代，祖先与后代重复选中时只处理一次，对应卡片同时移入回收站，关联 PDF 标注立即消失。每次批量修改作为一次撤销。

拖动已经选中的卡片可预览移动所选分支，包括折叠的后代；整组位置拖动不改变父关系或关联。只有全部顶层所选分支的位置均自由时才一次保存，否则松手后整组归位；从自动根主题开始拖动仍平移画布并保留多选。保存失败撤回整组位置预览。

单击画布卡片只选择并按联动模式处理，不弹出卡片悬浮工具栏。右键一级菜单最多 8 项：新建子主题、同级主题、编辑、回到原文、复制与移动、样式、折叠与展开、删除。无来源或无子主题时隐藏相应项；复制/剪切/粘贴及跨图操作、主题格式/卡片颜色、普通/递归折叠分别进入子菜单。删除按实际范围显示删除卡片或删除分支，继续可撤销；关联、外框、概要使用右下角「更多」菜单，分支结构使用其中的「脑图结构与整理」子菜单或大纲入口。

「关联卡片」或画布焦点下 `Ctrl+Shift+R` 可建立关系：选中两个主题时直接连接，选中一个时选择终点，未选中时依次点击起点和终点。关联模式下点击空白创建自由主题，创建终点及关系共用一次撤销；`Esc` 取消待建关系。

选中关联后按 `Space`、双击关系说明或点击「编辑关系说明」输入描述；`Enter` 保存、`Shift+Enter` 换行、`Esc` 取消。中文组词中的 Enter 不提交草稿。说明可以拖动，切换视图和返回主页会先保存，失败保留输入。

「关联线样式」可选直线／曲线／折线、颜色、粗细、虚线、两端箭头和文字样式；颜色也可跟随任一端主题。曲线选中后拖动方形控制柄调整弯曲，圆形端点可拖到其他主题重连或固定到主题边界。拖动仅预览，松手提交一次；空白松手、取消或失败恢复原线。「重置样式」清除手动曲线和锚点，保留关系说明；适合全部同时包含关系与说明。

选择主题后点击「添加外框」或按 `Ctrl+B`，为同一分支的连续范围分组；不同分支分别生成外框。外框包含可见后代并跟随移动和折叠，范围中间新插入的主题自动纳入。单个自由主题可以添加外框，多个自由主题请分别添加。

点击边框或分组说明选择外框，按 `Space`、双击说明或点击「编辑外框说明」输入文字；`Enter` 保存、`Shift+Enter` 换行、`Esc` 取消，中文组词不会误提交。拖动上下蓝色控制柄调整同级范围，松手保存一次，取消或失败恢复原范围。「外框样式与范围」也支持键盘选择起点／终点，以及圆角矩形、矩形、椭圆、填充透明度、边框和文字样式。重置样式保留说明与范围。

选择外框后按 `Delete` 或点「删除外框」只删除分组，保留主题。整分支复制保留完整外框，局部复制不生成残缺分组；每次修改都可撤销。切换大纲或返回项目主页会先保存说明草稿，保存失败会留在工作台。

### 个人思考与常驻编辑面板

双击画布卡片正文、按 `F2` 或右键「编辑卡片」打开编辑面板；双击标题继续使用局部标题编辑。标题和正文自动保存，「个人思考」按条管理，右侧加号添加，可逐条编辑和删除。条目不显示编号和占位提示；选中该条思考才显示右侧删除按钮，点到其他内容后隐藏。输入区随内容展开，未填写的输入草稿不保存；旧个人备注完整保留为第一条思考。复制、搜索和完整备份均保留分条内容。

面板打开后在同一项目内常驻。普通单击其他卡片会先保存旧卡标题、正文和个人思考，再切换内容，不自动抢占正文焦点。点击画布空白会清除脑图选择，面板仍显示原卡；操作 PDF、切换画布/大纲也保持面板。同项目切换脑图或当前卡片被删除后显示「请选择卡片」，选中卡片后更新内容。

点击叉号先保存再关闭；保存失败保留面板和草稿，处理错误后可重试。关闭后普通单击卡片不重开，需双击正文、F2 或右键编辑。返回首页、更换项目或恢复资料库后重置面板。宽屏停靠、窄屏浮动及窗口/文字缩放保留同卡草稿与焦点。

明确打开编辑器时，布局完成后同步交接正文焦点，随后可点击标题或任一思考输入。右键编辑操作实际目标卡片；画布/大纲及视图工具栏焦点下 `F2` 编辑最新主选并聚焦正文，保留多选集合。文字输入焦点继续使用自身快捷键。Ctrl 点击、拖动或取消手势不会触发双击编辑。摘录原文快照只读，修改正文不会改写它。

面板顶部当前色圆点提供「卡片颜色」入口，点击展开七色色板；选择立即提交，取消不修改。画布右键「样式 → 卡片颜色…」和多选改色使用相同规则：先保存文字草稿，再同步该卡片明确关联的全部 PDF 标注，不跳转原文。卡片与标注共用一次事务和撤销/重做，失败全部回滚；PDF 标注的透明度与区域保持原样。

重新选择当前色可修正旧关联标注的色差；全部颜色已一致时不新增历史。独立副本和无关联标注保持各自颜色，不按相同原文位置推断关联或补建标注。使用 Ctrl+C 后粘贴或「复制与移动 → 复制到其他脑图…」创建的独立副本，其标题、正文、个人思考和脑图位置都不会改变原卡片，不可变原文文件可以复用。

图文联动可选择双向联动、文档到脑图、脑图到文档或关闭联动。在画布或大纲中普通完整单击摘录卡片立即按模式跳转原文，不等待双击；拖动卡片不触发回源。点击 PDF 的摘录高亮按模式定位、展开脑图路径，大纲会显示实际目标行，自动联动不会强制打开编辑区。主题没有原文来源，单击只选择主题，画布双击仍可进入正文编辑。

点击编辑区「回到原文」或主题菜单的回源入口会明确跳转并显示来源范围，此操作不受自动联动模式限制。回源保持跳转前的 PDF 缩放比例，跨文档也不重新适配摘录大小。来源使用淡蓝连续底色短暂强调，1.5 秒后淡出，没有逐字边框；持久标注继续按其保存颜色显示。脑图分支删除同时回收卡片；撤销或回收站恢复卡片后，关联标注重新显示。历史上已移除节点但仍保留的卡片不会被自动回收，其孤立标注不再显示。

## 搜索、回收站与备份

使用搜索或按 `Ctrl+F`，搜索当前项目的卡片与已建立的文档文字层，支持单个中文字。点击卡片结果进入卡片，点击原文结果跳转到页内命中位置。尚未完成识别的扫描页需要等待 OCR。

资料和卡片菜单提供删除/移入回收站入口。工作台「资料库操作 → 当前项目回收站」只显示当前项目内容；首页左下角「资料库设置 → 回收站」包含所有项目及内容，可恢复已删除项目。原文移入回收站后，已有摘录仍保留来源版本与文件，可以回源。恢复脑图或卡片时，如果恢复结果会让同一卡片同时位于多张有效脑图，操作会完整拒绝；先移除或回收冲突位置，再恢复，历史记录不会被静默删掉。

回收站的「永久清理」先检查正常数据、回收数据和会话撤销记录的引用。仍被卡片使用的原文不能清理；需要放弃撤销记录时，确认框会明确显示影响。完整备份自带资源，清理活动资料库不会删除已保存的备份。

首页左下角「资料库设置 → 完整备份…」保存整个资料库，包括分类、阅读记录、笔记、原文、附件和文字层。封面缓存可重新生成，不进入完整备份。备份不依赖原机器的文件路径。

首页「恢复整个资料库…」会校验所选备份，并在切换前保存当前资料库的安全备份。旧版备份先在暂存区升级成功再切换。恢复后回到首页，清空旧编辑状态和会话撤销历史，界面显示旧库安全备份的位置。

## 快捷键与首版边界

| 快捷键 | 行为 |
| --- | --- |
| `Ctrl+F` | 首页聚焦项目搜索；工作台搜索当前项目 |
| `Ctrl+N` | 首页新建项目；工作台新建主题 |
| `Tab` / `Insert` | 画布或大纲焦点下创建选中主题的子主题 |
| `Enter` | 脑图焦点下创建选中主题的同级主题 |
| `Shift+Enter` / `Ctrl+Enter` | 画布或大纲焦点下插入前面的同级主题／上层主题 |
| `Space` | 画布或大纲焦点下编辑主题标题 |
| `方向键` / `Home` / `End` | 画布父子及同级导航；大纲按可见行和层级导航，不自动回源 |
| `Shift+方向键` | 画布加入多选，大纲扩展或收缩连续范围 |
| `Shift+空白拖动` | 画布临时追加框选；也可通过右下角「更多 → 框选卡片」开启框选 |
| `Alt+方向键` | 左右升降层级，上下调整同级顺序 |
| `Ctrl+A` | 画布或大纲全选可见节点；折叠后代由分支命令自动包含 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 画布或大纲复制、准备剪切、粘贴分支或文本大纲 |
| `Ctrl+Delete` | 仅当前卡片移入回收站，子主题提升一层并保留顺序 |
| `Ctrl+Shift+R` | 画布创建关联，未选中时依次选择两端 |
| `Ctrl+B` | 画布为所选分支添加外框 |
| `Ctrl+Shift+S` | 画布为所选主题添加概要并编辑概要标题 |
| `Ctrl+Z` | 非文本输入焦点下撤销资料库命令 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 非文本输入焦点下重做 |
| `Delete` | 非文本输入焦点下将所选脑图分支及后代卡片移入回收站 |
| `F2` | 画布/大纲或视图工具栏焦点下编辑最新主选并聚焦正文，保留多选集合 |
| `Esc` | 取消标题编辑或框选；画布焦点下也可取消拖动、待建关联或关联线选择 |

文字输入框保留自己的编辑撤销。资料库撤销只保留本次会话的可撤销操作；关闭程序或恢复备份后不保留撤销历史。导入和整库恢复不作为普通可撤销编辑处理。

选择同级主题后，使用画布右下角「更多 → 添加概要」或 `Ctrl+Shift+S`：同一分支的首尾范围合并为一个概要，不同父分支分别创建。概要主题可用 Space 或标题双击编辑，用 Tab 添加子主题；正文、个人思考和 PDF 来源继续使用共用卡片编辑器。选择概要主题后拖动括号的蓝色手柄调整范围，Esc 或指针取消不保存；「概要样式与范围」调整括号、线条、主题表面和字体，保存一次即可撤销。删除概要主题会移除该主题分支的显示位置；「移除概要括号」保留主题与子主题。复制完整范围或其上层分支会包含概要，复制部分范围不复制括号；新建时多个自由主题需分别添加概要。

选中主题后，画布右键「样式 → 主题格式…」或大纲右键「主题格式…」调整格式。「主题」页签提供圆角矩形、矩形、胶囊，填充、边框颜色／粗细／虚线，以及标题字体、10–32 字号、颜色、粗体和斜体；「分支」页签提供曲线、直线、折线、粗细、虚线、两端箭头和跟随卡片颜色。普通主题控制连接到自己的分支线，概要主题控制其子分支线。支持精确多选，勾选「同时应用到子主题」可覆盖后代；保存一次即可撤销，正文、个人思考、来源及位置保持不变。

画布「更多 → 脑图结构与整理 → 脑图默认格式…」（大纲仍使用页头入口）修改本图默认格式，新增主题及未单独设置格式的主题随之更新；勾选「设为本图默认格式」可在应用选集时一并设置。普通主题「恢复默认」移除其独立格式，概要主题恢复当前图默认表面与分支；默认格式弹窗的「恢复默认」恢复应用初始格式。复制或跨图移动保留当时的有效格式，副本不受源图后来默认格式变化影响。卡片颜色仍用于内容标记，与主题填充分别设置。

首版面向 Windows 11 x64，离线运行，不包含平板手写、云同步、复习、云端 AI 或标准 PDF 批注写回。
