# UI 行为合同

更新日期：2026-10-08。本文记录当前生效的操作语义，供回归检查使用。颜色、排版与装饰统一以 [UI 设计准则](ui-design.md) 为准。

## 项目与资料导航

普通启动进入项目首页。新建、分类、改名、移动和删除项目沿用原有入口；返回首页等待工作台保存，失败则保留当前草稿。搜索点击或 Ctrl+F 聚焦展开，有查询时保持展开，清空且失焦后收起。分类与滚动位置保持现有恢复逻辑。

项目有至少两份文档时显示文档标签行，使用已打开集合切换、关闭与排序；不按已打开标签数量决定整行显隐。阅读器保持组件身份，标签显隐不重建阅读状态。添加文档仍通过资料栏加号和阅读区空状态进入。资料／卡片、画布／大纲保留原有切换和窄栏菜单。

PDF 与知识区默认比例由当前视觉规范定义，保留手动分栏和显示／隐藏规则，至少显示一侧。资料栏在窄窗口通过原有抽屉入口打开。资料栏、编辑器的显隐状态不因视觉改造重置。

## 保存、退出与反馈

自动保存、关闭提交、返回首页、退出程序和资料库恢复保持现有串行合同。关闭继续请求 Flutter 生命周期，等待编辑提交、OCR 排空、封面释放和资料库关闭；失败取消退出并保留草稿。不能由窗口按钮直接销毁进程。

保存反馈初始隐藏；待保存／正在保存持续显示，完成显示 1.5 秒后隐藏，失败持续显示。切卡片、项目、会话或销毁使旧计时器失效；等待弹窗选择不显示正在提交。删除、改色、折叠、摘录、翻页通过内容变化反馈，继续可撤销。复制／剪切反馈 2 秒，不阻挡输入。错误和处理中状态不能因界面精简而隐藏。

## 阅读与摘录

PDF 工具栏按面板宽度 720、520、360 分档收纳操作，保留页码导航和目录入口；文字处理入口按当前文档状态显示。页码输入支持回车跳转，输入宽度容纳四位数字且翻页不跳动，当前页和总页数统一字号与基线。选区相关菜单保留选区，取消菜单及视图命令沿用原来的清除逻辑。PDF 和脑图不增加缩放百分比或数值缩放弹窗。PDF 保留放大、缩小、适配；脑图保留适合全部、滚轮与捏合，画布移除缩放加减按钮。

PDF 目录开关与宽度按文档版本独立保存，切换文档、返回项目和重启恢复各自设置；同字节的独立文档也不共用偏好。拖动结束保存宽度，主动开关或关闭目录抽屉保存显隐；窗口临时变窄不覆盖保存宽度。停靠目录打开后，PDF 在剩余阅读视口内居中；适合宽度／整页模式持续生效并保留纵向阅读位置，手动缩放保留缩放与阅读锚点。窄栏抽屉支持关闭按钮、遮罩和 Esc，目录跳转后收起。

目录分隔线保留 6 像素拖动区、水平调整光标及悬停／拖动反馈。PDF 滚动条随滚动显示，闲置 1.5 秒后淡出；右边缘可唤出，悬停和拖动保持可见。唤出区域不吞正文点击或平移，滚动条拖动继续定位整本文档。

回源保持阅读缩放，仅平移到来源；临时强调按同一行合并邻近字框，不跨行、跨栏，沿用现有停留与淡出时长。标注沿用保存的颜色，文字选区与持久标注共享显示区域和点击命中，原始锚点与文字范围不变。

PDF 导入／打开自动处理文字层，当前文档的进度、失败和取消继续提供相应入口；PDF 收起时，未完成或失败状态保留页头入口。全部页面就绪、没有活动任务与错误时，隐藏文字处理按钮并收回占位；由未完成变为完成时提示“文字识别完成”约 1.8 秒，切换文档或会话使旧提示失效，进入已完成文档不重复提示。窗口顶部“更多 → 文字识别状态”继续提供当前 PDF 的状态详情。重试仅恢复失败页，继续仅恢复取消页，保留已完成页，不混入其他文档状态。EPUB 保留章节、进度、正文索引、图片识别及用户阅读设置。

选区端点继续调整选区，从选区按住左键可拖出完整文字。有效脑图空白落点创建顶层卡片，卡片落点创建子卡片；自动布局决定最终位置，自由布局使用落点。成功后选中新卡片、清除选区并保留持久标注；失败、无效落点和 Esc 取消保留选区，不创建卡片。一次拖入对应一次事务和一次撤销。切文档、脑图、项目、恢复资料库或退出使旧拖动和异步结果失效。

## 卡片编辑与样式

右键菜单与打开同内容菜单的省略号入口共用展示与导航。脑图“复制与移动”“样式”“折叠与展开”保持现有分组，子菜单侧向展开，父菜单保留原位，无“返回”项目。上下键跳过禁用项，右键进入子菜单，左键和 Esc 返回父项，主菜单 Esc 或外部点击关闭整组；取消不执行业务命令。菜单只返回一次叶子动作，沿用页面的多选、目标与会话检查，目标失效或页面卸载时取消。关闭后恢复原焦点，外部关闭点击不触发底层画布动作。动画与尺寸以视觉规范为准。

双击、F2 或右键编辑打开面板，同项目内保持打开直到主动关闭。单击其他卡片先保存原草稿，再切换内容，不抢正文焦点；画布空白清除选择但保留编辑内容。阅读操作和视图切换不关闭面板。切脑图或删除当前卡片后保留面板并提示重新选择；返回首页、换项目或会话失效后重置。保存失败时不能关闭丢失草稿。

编辑器 key 与组件层级在断点变化时保持稳定。正文、个人思考和来源内容不因布局变化重写。思考条目独立排序，空草稿不入库；删除按钮仅在对应条目聚焦时显示，预留位置避免输入跳动。自动保存、撤销、复制、搜索、备份恢复保持分条内容。

七色色板保留既有立即保存语义，取消不修改。改色仅在一次事务与撤销中同步明确关联的 PDF 标注，保留透明度、几何及独立副本颜色；不按位置猜测关联，不回写全部旧数据。主题／关系／外框／概要等样式弹窗保留各自现有的应用、取消与重置语义。

卡片回源仅在真实来源存在时提供；未放入当前脑图的卡片也按真实来源判断。右键菜单保留新建、编辑、回源、复制移动、样式、折叠展开及删除的原有分组、快捷键与可用条件。

## 脑图操作

画布右下角使用一个「新建／更多／适合全部」工具组，无上方创作工具条。新建沿用现有主题创建与快捷键；更多向上打开共享菜单，结构与整理侧向展开，框选、关联、外框、概要保留原有可用条件与命令回调。菜单打开期间图或选集失效则取消，叶子动作只派发一次；关闭恢复焦点。框选与关联的模式提示位于工具组上方，Esc 先退出当前模式；普通空白拖动、Shift 临时框选及原有快捷键不变。大纲保留页头创建与结构入口。

新建脑图继续默认向右自动排版。自动布局根节点拖动平移画布，不写节点坐标、不新增撤销；自由布局根节点仍移动自身分支。自动布局节点拖到无效空白立即归位；有效目标继续改变父子关系或同级顺序。多选移动保留自由布局判断，混合分支以所属父级布局为准。保存后的坐标接管预览，缩放与选择保持稳定。

滚轮缩放参数保留 scaleFactor 800，范围 8%～250%，围绕鼠标缩放；捏合与程序缩放接口步幅不变。关联、外框、概要、框选、控制点和范围手柄保持原有命中、事务和撤销边界。

有后代且被选中的展开主题显示折叠入口；折叠主题常驻全部后代总数，叶主题无入口。折叠入口按有效分支方向定位。点击先单选再切换，不触发回源、正文编辑或拖动。普通展开保留深层折叠状态；Ctrl+/ 切换主选，Ctrl+Alt+/ 递归处理，文字编辑焦点不截获。多选与全图展开层级保持原有入口。

## 窗口、沉浸式与光标

进入沉浸式在当前显示器真实全屏，隐藏窗口栏和资料栏，内部工具保留；提示 Esc 退出 1.5 秒。Esc 优先结束临时交互，再退出沉浸式；正文输入焦点不阻止退出。退出恢复窗口位置、大小、最大化与资料栏状态，并保留阅读位置、缩放、画布视图、分栏和草稿。失败反馈错误，离开工作台或会话失效时恢复；沉浸状态不持久化。

普通按钮保持桌面箭头，文字使用 I 形，分栏使用水平调整光标。平移、抓取、框选、关联、控制点和混合分支范围手柄保留原来的专用光标与取消规则。光标覆盖不截获输入，不触发全文加载或仓储写入；后台 OCR 不改变其他区域光标。

普通还原窗口四角使用系统圆角，最大化和全屏使用直角；最大化／还原图标与实际窗口状态同步。窗口关闭、缩放、DPI 变化、最大化、系统贴靠和全屏恢复均不得绕过以上合同。原生 `WM_CLOSE` 明确请求 Flutter 的可取消退出，不依赖辅助窗口数量判断；最小化时保留 Flutter 最后一次有效客户区尺寸。
