# EPUB／PDF 全流程兼容需求

用户已于 2026-10-06 确认计划并授权实施。运行平台为 Windows 11 x64，仅使用系统 WebView2。

1. 导入无 DRM 的 EPUB 2／3 与 PDF 时，系统保存不可变原件，同一项目允许混合管理。
2. 阅读 EPUB 时，系统支持可重排、固定、混合及中日韩竖排，正文、图片、表格、SVG、MathML、目录、脚注和内部链接。
3. 摘录文字、原图或可见区域时，系统建立独立卡片、批注及稳定来源；重排后仍定位相同内容，区域卡片保留原截图。
4. 搜索、跨项目复制、改色、撤销、回收、恢复及备份均保留两种来源格式。
5. 调整阅读状态或退出时，系统先保存并关闭相关资源；旧会话消息不得写入新资料库。
6. 图片 OCR 按需执行，结果可追溯且不覆盖原生正文或旧快照。
7. 升级历史库时先保存一致性快照，失败回滚；旧备份暂存升级成功后才激活。
8. WebView2 缺失时 EPUB 显示安装提示，PDF 继续使用现有引擎。

不包含音视频、书籍交互脚本、DRM 接入、云同步及原文件批注写回。资源与处理保持离线。
