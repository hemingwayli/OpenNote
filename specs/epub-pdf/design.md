# 实施设计

- PDF 沿用 pdfrx／PDFium；EPUB 使用 flutter_inappwebview 6.1.5、epub.js 0.3.93。本地资源经仅监听回环地址的会话服务提供，书籍脚本与远程请求禁用。
- 文档格式与来源定位分离。PDF 的页码、坐标、文字层仍保持原语义；EPUB 使用章节路径、CFI 范围与原文校验，图片附加相对裁剪范围。统一摘录与回源接口不把 EPUB 章节伪装为 PDF 页。
- 保留原件，解包与封面为可重建缓存；截图及 OCR 结果是持久资源。EPUB 文本索引保留文本到 CFI 的映射。
- v11 迁移扩展定位与 EPUB 索引，先一致性备份。历史 PDF 的字段与身份保持不变；新增 EPUB 定位具有格式标记并在读取／恢复时严格校验。
- 会话、版本、请求序号隔离所有异步回调。编辑、复制、撤销、批注改色共用现有仓储事务。
- UI 沿用 docs/ui-design.md；可重排默认单栏连续阅读，支持分页与排版设置；固定版式保留原布局。
- 真实 WebView 交互通过独立开发资料目录验证；Flutter 替身只验证业务约定。最后串行全量回归与候选包验证。
