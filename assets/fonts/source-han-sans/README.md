# 思源黑体简体中文

这些字体直接取自 Adobe 官方 `adobe-fonts/source-han-sans` 仓库的 `SubsetOTF/CN`，未修改、转换或裁剪。

`provenance.json` 记录固定上游提交、下载 URL、字节数及 SHA-256。`LICENSE.txt` 是同一提交的完整版权声明和 SIL Open Font License 1.1。

Flutter 使用 `Source Han Sans CN` 家族，映射 Regular 400、Medium 500、Bold 700，优先承担中文显示。三个字重随应用分发，用户无需安装系统字体。应用的“开源许可”可阅读完整授权文本。

字体许可不替代项目或其他第三方组件的许可。保留这些声明，不单独销售字体；如将来修改字体，先核对 OFL 的保留名称等要求。
